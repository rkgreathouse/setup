# Glacier Night Vivid for IntelliJ

IDE theme and editor color scheme. Install `build/GlacierNightVivid.jar` with
**Settings → Plugins → ⚙ → Install Plugin from Disk**, then pick Glacier Night
Vivid under **Appearance → Theme**. Rebuild with `./build.sh` (needs `jar` from
a JDK). Needs IntelliJ 2025.3 or later.
